# 我的班固米墙（bangumi_wall）

把自己在 Bangumi 上收藏的番剧 / 书籍 / 游戏 / 音乐 / 三次元，做成一面封面墙，以便快速展示成分

此项目非官方项目

发布页：https://bgm.tv/group/topic/470228

## 功能

- **两种绑定方式**：OAuth2 登录（可看私有收藏），或只填一个用户名（只看公开收藏）
- **类别多选**：动画 / 书籍 / 游戏 / 音乐 / 三次元，标签上带条目数，可任意组合
- **收藏状态多选**：想看 / 看过 / 在看 / 搁置 / 抛弃
- **卡片文字自由配置**
  - 标题：中文名 / 原名 / 隐藏
  - 小标题：年份、完整日期、收藏时间、我的评分、Bangumi 评分、排名、收藏状态、条目类型、观看进度 —— **可混选**，按点选顺序拼接
  - 一键「只显示封面」，两行全隐藏，纯封面墙
- **类别图标**：同屏混着多个类别时，封面右上角标出条目类型，可关闭
- **两种视图**：封面墙 / 列表，列表带缩略图和吐槽
- **显示吐槽**：把自己写的短评显示出来，封面墙和列表都支持，把鼠标移到封面上也会显示
- **同系列相邻排序（不稳定）**：一部番的不同季在墙上挨着放
- **生涯个人喜好表**：`/grid`，从左栏收藏拖进格子，题目可改，导出成图
- 排序（收藏时间 / 我的评分 / Bangumi 评分 / 排名 / 发行日期 / 名称）、搜索、三档封面尺寸

## 生涯个人喜好表

`/grid`。灵感来自 [itorr/anime-grid](https://github.com/itorr/anime-grid)（动画生涯个人喜好表生成器），和原版的区别是**不用搜索，直接从左栏自己的收藏拖过去**。

- 五个类别各一张表（动画 / 书籍 / 游戏 / 音乐 / 三次元），题目按类别有不同默认值
- 左栏是当前类别的收藏，可搜索、按收藏状态筛，已用过的会淡化
- 拖进格子，或点选后再点格子（手机上 HTML5 拖拽不可用，点选是兜底）
- 格子之间可以互相拖动交换
- 收藏里没有的作品：点空格子在 Bangumi 全库搜索，选中后填入（这些条目单独存一份，刷新后还画得出来）
- 题目直接点着改，可以增删，列数 3–6 可调
- 导出 JPG，图上带原项目署名
